# .github — Metrik org meta

Org-level community-health files and cross-repo docs for **Absol-Labs / Metrik**.

- [`profile/README.md`](./profile/README.md) — the org profile landing page.
- [`ROADMAP.md`](./ROADMAP.md) — cross-repo roadmap (Model A).
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — how to develop across the repos.
- [`docs/CODEX-KICKOFF-MODEL-A.md`](./docs/CODEX-KICKOFF-MODEL-A.md) — the current AI-agent
  (Codex) kickoff for the Model A build.
- [`docs/codex-playbook.md`](./docs/codex-playbook.md) — the cross-repo working playbook.
- [`SECURITY.md`](./SECURITY.md) — org security policy.
- [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE/) — default issue template for org
  repos that don't define their own.

These files apply org-wide via GitHub's community-health-file defaults.
